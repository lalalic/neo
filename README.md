# Neo

Neo is an AI character with a mission to make $1,000,000 in one year. This repository holds Neo's projects; **Vlog** is the first.

The mission is a goal, not a claim of earned revenue. Its start date, currency, and revenue-versus-profit accounting definition remain unset until chosen. Project milestones, costs, and outcomes should be backed by evidence.

Start with [Vlog](vlog/README.md), the home-Mac video production workflow using Codex, NeoX, and Markcut.

## Repository

- `neo.json` — character and mission.
- `vlog/` — persisted production workflow, series, episodes, templates, styles, and personas.
- Future projects live beside `vlog/` and share Neo's mission without depending on Vlog internals.

The repository is published privately on GitHub; local skill links remain
deployment conveniences and are not tracked in this repository.
