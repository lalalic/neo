# Preview a Vlog Markcut template

The executable template is [cinematic-vlog.md](cinematic-vlog.md).
Editor uses it as an **executable scaffold**, instantiates the fixed brand intro and prepared root music, then authors the dated Run's canonical `video.md` directly with Markcut DSL. Scene structure, selected BGM, root sound volume, subtitles and effects are authored in executable `video.md`, not generated by a separate Vlog compiler.

A short demonstration file, [cinematic-preview-demo.md](cinematic-preview-demo.md), is a synthetic editing fixture and **not** a real episode. For a sandbox preview, copy it under ignored `runs/<dated-test>/video.md`, then open it in Markcut Preview. Synthetic media do not establish permission to publish.

For a real episode:

1. Director/Editor supply approved source files, source hashes, scene IDs, story progression, in/out timing and transitions.
2. Editor chooses licensed/source-matched BGM, authors the full `video.md` with [cinematic-vlog.md](cinematic-vlog.md) as a style guide, and runs `markcut verify video.md` on the exact file.
3. Producer re-verifies and renders with Markcut CLI; `markcut preview` is optional, only when review is requested. Changes return to Editor for a new verified revision.
4. Probe the real rendered MP4's video/audio streams; optional human review and separate publication consent have their own gates. A template preview does not grant approval.

Do not embed demo URLs, invented source footage or unverified GPS in a production run. Any optional route scene is assembled from [geo-story.md](geo-story.md) or [route-overview.md](route-overview.md); map tiles, narration and endpoint visibility require real playback verification.
