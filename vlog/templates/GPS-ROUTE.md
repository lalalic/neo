# Geographic inserts — template reference

Executable Markcut templates: [geo-story.md](geo-story.md) for a narrated geographic chapter, [route-overview.md](route-overview.md) for a simple route overview. The primary episode remains [cinematic-vlog.md](cinematic-vlog.md), which incorporates a **verified rendered** route scene where Director selected it.

Use source-verified EXIF/QuickTime locations, timestamps and owner permissions. The source's exact GPS can remain in a private preview; public distribution requires authorization covering any precise or sensitive location shown. Reject false stops, joined time intervals, implied travel modes and invented dialogue. Google Directions is an optional road navigation reference, **not** a recorded route.

Map/audio leaves and scene structure are defined by the two Markdown templates, not by a competing JSON preset or this guide. Producer must verify that route audio, map tiles, coordinates, playback and root BGM actually render. With no credible GPS, omit the route without blocking the rest of the episode.
