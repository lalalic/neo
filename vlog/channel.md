# IT佬加国砰砰砰 — 频道定位与选题

这是公开频道的创作策略，不是私人画像；私人背景和披露权限仍由 `user.md` 管理。

**频道主张：** 加拿大打工 IT 佬，工作、陪娃、旅行、折腾 AI；生活磕磕碰碰，给日子加点料。真实、松弛、偶尔自嘲；中年困境是人物底色，不是每集的苦情任务。

## 六大内容方向（每条视频至少围绕其中一个）

| ID | 方向 | 观众为什么看 | 素材中的实际抓手 |
| --- | --- | --- | --- |
| `ai` | AI 折腾 | 想看 AI 真能做什么，以及好笑的失败与成果 | 项目、尝试、操作、成败、实际体验 |
| `it_work` | IT 工作 | 对国内外 IT 职场、技术、管理与职业变化感兴趣 | 本人已确认的工作经历、非涉密实践 |
| `work_permit_pr` | 加拿大工签 / PR | 需要理解工作身份与移居相关的真实经验 | 本人经历、可核验的官方公开信息；不做无资质有偿个案移民建议 |
| `family_education` | 陪读 / 家庭 | 好奇加拿大教育与父母的日常 | 本人愿意公开的陪娃、教育与家庭片段 |
| `travel_explore` | 加国旅探 / 生活 | 想体验真实加拿大，发现新鲜事 | 当次确有的行走、地点、生活观察与尝试 |
| `midlife` | 中年生活 / 困境 | 关心职业、责任、选择，也想看人如何找乐子 | 本人许可表达的感受、具体生活行动；不消费家人隐私 |

## 每期选题规则

- **必须选出一个主方向**（`primary`），可以选择其他有真实素材支撑的辅助方向（`secondary`）。不要求六个全出现；不要为了满足方向而虚构镜头、任务或情绪。
- 先从 Visioner 的真实素材与已确认的本人经历找看点，再选最贴合的方向与目标观众。明确回答：观众为什么点进来、能看到什么、看完得到什么。
- 主方向必须有本集实际来源支撑。标题、开头和结尾兑现同一个观众期待；若素材不能支撑原先的选题，应改小选题或补拍，不得硬套人设。
- 默认中文，像熟人聊天，轻松、有观察、有适度自嘲；允许安静、真实环境声，允许没有挫折或励志结尾。
- `user.md` 中的私人家庭、年龄、情绪及履历仅作内部参考，未经当期同意不自动进入标题、旁白、字幕或发布文案。
- 发布后的实际观看与评论数据可帮助下一期调整选题，不能宣称未经验证的流量效果。发布仍须单独授权。

**结构化落地：** 从 2026-11-09 起的新 Run，Director 在 `personal-story.json` 写入 `channel_focus`：`primary`（六个 ID 之一）、可选 `secondary`（其他 ID）、`viewer_reason`（观众为何看）、`source_ids`（本集 Visioner 源 IDs）。Editor 继承这个主方向，按真实画面审核是否兑现观众承诺；无须增加 DAG 节点或人工审批。
