# Vlog Director MVP — eight required decisions

One Director, existing DAG and existing Stage artifacts. The Editor owns the executable timeline, effects, TTS and final `video.md`; Director owns ideas, story and source-linked planning. **Give usable footage room to form a complete experience** rather than cutting the episode to a tiny hook. Do not invent filmed behavior, private thoughts or conversations; use imaginary comparisons, playful captions, creative reflection and humorous hypothetical language as **commentary**, not claims of fact.

## Eight MVP capabilities (preflight #6 runs before choosing #1–2)

1. **Six direction selection.** Read `channel.md`. Choose one primary among `ai`, `it_work`, `work_permit_pr`, `family_education`, `travel_explore`, `midlife` and source-backed optional secondary directions. Save to `personal-story.json.channel_focus`. All six are eligible, but only source-relevant ones belong in this video.
2. **Audience-oriented hook stories.** Decide who in China would watch this, why they would click and what the full story promises. Explore up to three substantially different *candidate* story lenses privately, then choose the strongest. For explicitly requested Interactive Review, present 2–3 contrasting Hooks with each Hook's pillar, viewer reason, source clip, guide and preferred option; don't send review unrequested. A Hook is an entry to the film, not the whole 2-second film.
3. **Complete story.** Read the entire source manifest and Visioner facts, inspect the person/action/audio at real timecodes and create `personal-story.md/json` (complete conversational first-person narrative), `story.md` (beats and editor intent), `shot-selection.json`, `visual-brief.md`, and `post.md`. Include a `素材盘点与取舍理由` table in `visual-brief.md`: every source ID, story value, use/omit rationale. Prefer meaningful coverage over a single micro-split, but never include filler. Humor, subjective reflections, cultural contrast and imaginative verbal play are wanted; fictional events/owner statements are not.
4. **Interactive on demand.** Default automatic best story and no Review. If `review-stages.json` requests `director:true` or Task instructions explicitly request Director review, create 2–3 source-backed Hooks, `director-hooks.md`, Markcut verify and an immutable Git checkpoint; call the Neo-hosted `markcut.preview` tool with **the current child/Director Task's verified Relay identity**, and await real `AWAITING_DECISION`. Do not treat successful notification as approval. The current in-flight old requests must not be overwritten or duplicated. Approval applies only to matching revision.
5. **Route and spots; story-weak fallback.** Inspect observed place/stop clues from approved metadata and GPS. With trustworthy filmed spots, describe them in `route-intent.json.observedStops` and `audienceContext` with source references. An **observed spot is not proof of a traveled route**. If GPS is missing, narrate safe visual context, omit geospatial route. When a strong personal plot is not evident, **fallback** to (a) an observational outing with varied scenes, (b) a truthful location/spot-guided journey, (c) interesting comparisons or a calm reflective diary with a small honest end. Do not manufacture a problem, goal, family drama, walking route or precise geography just to complete a story. Still give Editor enough real beats for a satisfying film; if sources are truly inadequate say what's missing and optionally request a real pickup.
6. **嘿 Neo material first.** Run `node scripts/director-mvp-preflight.mjs <run>` before choosing a hook. Preflight reads complete approved source IDs and *unverified* markers from Markcut metadata and local STT WebVTT. `prioritySourceIds` must be checked **first in original audio**. Spoken creator edit instructions are potentially the strongest intentional brief: accept verified keep/remove/emphasize intent unless it conflicts with user authority or safe/current Run constraints; propagate it clearly to Editor. ASR/Markcut hints are candidates, not verified instructions, and the command speech itself normally should not appear as Vlog narration.
7. **Real human behavior and sound.** Dense-sample original clips around face, hand, gesture, action and speech. Listen to actual source audio for quoted dialogue and `嘿 Neo` commands; uncertain STT stays uncertainty. Human action and reaction usually provide story choices more directly than landscapes. Original ambient sound can be an equally important beat.
8. **History.** Read `user.md` for private style only. Search `story-history.mjs search` on current topic and inspect only relevant indexed prior episodes. Reuse persona, avoid repetitious hook/tone, find callbacks where truthful. Never treat archive content as current footage, and do not disclose private family facts merely because they appear in profile. Missing history does not block the Run.

## Completion without false PASS

The Director's deliverables and existing validators remain authoritative. The preflight is read-only and produces **no new mandatory handoff contract**. No arbitrary 30-second cap, clip-count quota, gimmicky effect quota or new Relay task topology. Record a weak-story fallback choice explicitly in `story.md` and source omission rationale in `visual-brief.md`. Each selected shot still cites the actual source ID/hash/time, and route intent is always include/omit with evidence. For a requested human review, a pending interactive request is a *waiting state*, not a successful completed story approval.

Run the existing decision Evals plus `director-mvp-eight-capabilities` node tests and optionally the independent Markdown creative rubric `node scripts/eval-creative-artifacts.mjs --run <run> --stage director --judge`. These tests do not prove artistic success without real media inspection.
