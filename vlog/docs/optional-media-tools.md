# Optional media capabilities — load on demand

This is a conditional reference, not part of normal Worker startup. Load only if
a Director, Editor or Producer can name a specific evidence-backed improvement
from an optional platform. No extra Graph Task or second editing pipeline.

- Discover the shared `capcut-mcp` Skill from the execution context. Ask the
  installed `mcp.capcut` for its current `help` and command inventory; do not
  hard-code a fixed CapCut command list. Do not invoke tools solely because
  they are available.
- Director may gather visual references; Editor may evaluate candidate trims;
  Producer may acquire justified auxiliary material. Do **not** rerun or replace
  Markcut STT/VTT/vision, source evidence, canonical
  `edit-decision-list.json`, `video.md` or Markcut Preview.
- Before uploading private media, account/draft mutation or AI generation,
  obtain explicit approval under the Skill. Get approval for estimated credit
  cost before paid operations. Source-use approval does not authorize cloud
  upload.
- Verify source timecodes for edits, bytes/format for generated assets,
  licenses/rights for stock, and separation of illustration from recorded
  events. Record selected tool, purpose, provenance and authorization in the
  Stage artifact. Use `NOT_APPLICABLE` for an unused optional branch.
  Never claim an unverified asset was imported. A rejected/unavailable tool
  is not permission to bypass Markcut or owner consent.
