# One Episode Task — reusable stage contract

This is a design contract, **not** an episode, scheduler or authorization. It continues [PR #127](https://github.com/lalalic/neo/pull/127) and [PR #129](https://github.com/lalalic/neo/pull/129). Source approval is a prerequisite to *creating* a real Episode Task. The 2026-10-11 pilot manifest is `INPUT_NEEDED`, so no episode may be invented for it.

```text
owner-approved source -> Research? -> Story -> Production -> immutable Preview Review
                                   -> Video Director + Market reviews -> technical QA
                                   -> explicit Publish Authorization? -> publish with receipt
                                                                  \-> archive (default)
```

Each normal stage is work inside **one durable top-level Episode Task**, using the existing `vlog-editor -> vlog-producer` specialist agentGraph (a DAG). Relay owns durable decisions, retries, review revisions, escalation and exceptional child Tasks; do not add feedback edges to agentGraph, a new scheduler or a renderer.

| Stage | Accepted input / gate | Durable output under `runs/<episode>/` | Provenance and acceptance evidence | Hold or fail condition |
| --- | --- | --- | --- | --- |
| **Source** | Owner confirms episode window and grants use permission per authentic asset | `source-manifest.json` with source IDs, hashes, original location, rights/use status, selected in/out ranges and timestamp provenance | Checksum and permission reference per item; selected real images/video and original audio | `INPUT_NEEDED`, missing rights, unsuitable media, ambiguous episode window: no Episode Task starts |
| **Research (conditional)** | Approved manifest and story-relevant research questions; GPS metadata is optional | `route-evidence.json` or explicit `not-applicable` status, `location-enrichment.json` if relevant, research notes | Each fact links back to source ID, original EXIF/QuickTime metadata or attributable external source; capture timezone uncertainty, privacy and calculated-vs-observed distinction | Missing GPS is a successful no-op, not a pipeline failure; invalid/outlier/private GPS excluded; external permission holds only the affected enrichment |
| **Story** | Source manifest, optional research and authentic story beats | `story.md`, `post.md`, `visual-brief.md` | Hook/development/payoff references exact source IDs, shot ranges, original dialogue/ambient audio; generated context explicitly identified | Unsupported visits, invented movement/scene, unusable story evidence or invented dialogue: revise through Relay |
| **Production** | Story and visual brief with approved media; original sound and licensed/authorized BGM plan | `music-plan.json`, `video.md`, `execution/`, `assets/`, WebVTT captions | Source references per scene, licenses and music clearance, audible mix/ducking decisions, Chinese default text, visual/source-truth checks; optional map insert separately redacted and authorized | Missing BGM clearance, absent original media, unavailable rights, unapproved private location or unresolved Markcut output: hold; never replace source footage with synthetic demonstration |
| **Immutable Preview Review** | Canonical compiled draft, exact revision/content hash, human-accessible Markcut preview | Revision-specific preview and review record under `reviews/` | Reviewer decision bound to immutable revision and source/use scope; any changed draft invalidates earlier approval | Not reviewed or changes required: hold. Corrections create a new Relay task/review lifecycle, not an agentGraph back-edge |
| **Video Director + Market reviews** | Exact preview revision and draft | `reviews/video-director.md`, `reviews/market.md` | Explicit `PASS` from both, validating story/pace/source truth, sound mix, captions, platform/audience fit | Any `CHANGE_REQUIRED` or revision mismatch prevents final render |
| **Technical QA / archive** | Dual PASS, approved draft and resolved Markcut backend | `output/` render, `qa.md`, immutable archive receipt | Actually observe final pixels, source media, route tiles/camera when used, Play/Seek, sound/BGM and WebVTT; verify exact delivered video bytes | Compilation/local HTTP alone does not pass hosted preview. Job 474 hosted iframe bootstrap remains a separate unresolved gate; no fake acceptance. Archive is default without publication authorization |
| **Publish Authorization (optional)** | Accepted immutable output and explicit human authorization for platform/account/scope, including privacy and rights | `publish/` authorization reference; if authorized, shared post-agent receipt and platform verification | Record who approved which version, where and when, then post-agent platform-side status; retain archived copy | Without explicit authorization, **archive only**. No spending or posting by inference; missing receipt is not successful publication |

## Optional location semantics

No usable GPS -> research no-op -> full normal Vlog. Partial GPS -> only source-linked reliable stops, no guessed stops for other footage. Two or more trustworthy samples may permit a brief optional map/context scene **only** if editorially useful and separately authorized for disclosure. Filter ambiguous clocks, outliers, large gaps, inaccurate and sensitive points. Redact location; never upload raw GPS to a public mount. Road directions and cinematic camera paths are inferred visualizations, **never recorded movement**; do not invent presence, transport mode or visited places. Samples/tests are labelled synthetic and never substituted for episode footage.

The human preview is revision-bound, both required reviews precede render, and final technical QA is observed rather than inferred. Never publicly publish without explicit authorization.
